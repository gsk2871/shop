# 网站改版：后台配置操作说明

本文面向后台操作人员，说明网站改版涉及的配置入口、填写方法及官网展示效果。原表编号用于对照《网站修改建议.xlsx》。

使用前提：部署支持这些配置的后端、管理后台和官网，并完成数据库迁移及种子初始化。文档中的默认数据是初始化值，不代表当前环境已经写入。若页面没有对应字段，先检查服务版本；菜单不可见或无法编辑时，检查账号权限。

本地后台地址为 http://127.0.0.1:8000，官网地址为 http://127.0.0.1:3000。以下相对路径均指管理后台路径。配置保存成功后，刷新官网查看效果；只修改输入框、未点击保存不会生效。

## 二、优惠弹窗：原表 1、2、3

**入口：系统配置 → 留资弹窗配置。**

| 配置字段 | 填写说明 | 示例 |
| --- | --- | --- |
| 弹窗开关 | 控制优惠弹窗是否启用 | 开启 |
| 弹窗品牌文字 | 弹窗中的蓝色大号品牌文字，可留空 | NOVAPEPT |
| 报价小标题 | 独立的小标题，可留空 | PRODUCT LIST & QUOTATIONS |
| 报价标题 | 报价区域标题，可留空 | Request a Quote. |
| 主标题 | 优惠活动主文案，必填 | Want 10% off your first order? |
| 说明文案 | 补充介绍，可留空 | 按实际活动填写 |
| 输入框提示 | 提示访客填写邮箱或 WhatsApp，必填 | Email or WhatsApp (include country code) |
| 提交按钮文案 | 联系方式提交按钮，必填 | Get your discount right now |
| 拒绝按钮文案 | 关闭弹窗的按钮，必填 | No, thanks |
| 底部说明 | 联系授权及活动说明，必填 | 按实际业务填写 |
| 提交成功标题、提交成功说明 | 留资成功后的反馈，必填 | 按实际业务填写 |

填写后点击「保存配置」。文案面向官网访客，建议填写英文。文字颜色、字号、字重和按钮颜色由官网统一控制，后台没有这些样式配置项。

提交按钮执行联系方式校验与留资提交，成功后显示成功提示，不跳转 WhatsApp。留资可在「运营管理 → 留资记录」查看。同一浏览器标签页的一次访问中，弹窗关闭后不会自动重复弹出；检查效果时可通过左下角 Special offer 再次打开。

重复执行初始化保留已保存的文案。因此已有站点的主标题、提交按钮文案需要按本表自行核对。

## 三、页眉背景与全站背景：原表 4、19

**入口：系统配置 → 品牌与主题 → 页眉与背景图片。**

### 页眉背景色

设置「页眉背景色（只影响页眉）」，再点击「保存品牌与主题」。初始化颜色为浅蓝色 `#eaf4fc`。

该颜色仅影响顶部导航所在的页眉，不改变宣传条、正文或弹窗。选中导航文字加大、页眉 Contact us 的蓝底白字样式由官网固定处理，无需配置。

### 全站背景图片

1. 在「全站背景图片」点击「从媒体库选择」，选择图片。
2. 如需替换，点击「更换图片」重新选择。
3. 点击「保存品牌与主题」，刷新官网检查桌面和手机效果。
4. 如需恢复无背景图片的外观，点击「清除」，再保存。

未配置时保持原有背景外观。图片按页面尺寸铺设，显示区域可能随设备比例发生裁切，建议避免把重要文字放在背景图片中。

清除背景配置不会删除媒体库素材。图片被背景配置引用期间，媒体库禁止直接删除；需要删除素材时，应先清除配置并保存。页眉仍使用其独立背景颜色。

## 四、顶部宣传条：原表 8

**入口：系统配置 → 品牌与主题 → 顶部宣传条。**

| 配置字段或操作 | 说明 |
| --- | --- |
| 开启宣传条 | 整条区域的总开关；初始化默认关闭，需手动开启 |
| 背景颜色 | 仅影响宣传条背景，初始化为蓝色 `#2563eb` |
| 文字颜色 | 所有条目统一使用，初始化为白色 `#ffffff` |
| 滚动速率 | 慢、标准、快，初始化为标准 |
| 内容 | 每项填写一段非空文字，最多 30 项 |
| 每项的开启 | 临时关闭某条内容，无需删除文字 |
| 上移／下移 | 调整展示顺序 |
| 删除 | 移除该条内容 |
| 新增宣传内容 | 添加条目，填好文字后保存 |

初始化提供以下六条示例：99% Purity、10% off for the first order、Super affordable price、150+ Countries Served、24H Response Time、Contact us right now。开启前请核实文案与实际业务一致。

点击「保存品牌与主题」后生效。所有文字都不可点击，包括 Contact us right now，不提供链接或条目动作。

没有启用条目时整条隐藏；文字较短时静止展示；需要滚动时按选定速率播放。鼠标悬停或键盘聚焦暂停，系统启用减少动态效果时静态展示。

## 五、首页轮播：原表 6、7、17

**入口：系统配置 → Banner管理 → 新建或编辑。**

选择首页主视觉位置 `home_hero`，维护以下内容：

| 配置字段 | 说明 |
| --- | --- |
| 后台名称（不展示给访客） | 便于管理人员区分图片 |
| 桌面图片 | 首页电脑端图片，必填 |
| 手机图片（留空使用桌面图片） | 按需选择手机图片 |
| 关联商品（选填） | 决定是否显示 Shop Now，以及其目标商品 |
| 排序（较小优先） | 控制轮播顺序 |
| 启用状态 | 控制该轮播是否展示 |

Shop Now 只有在关联商品已发布、未删除且具有有效定价规格时显示，点击进入商品详情。未关联或商品不可访问时隐藏该按钮。

所有展示中的轮播都带有 Get 10% OFF your order，点击进入统一客服流程，不依赖关联商品。两个按钮文案、蓝底白字样式与位置由官网固定处理；手机窄屏上下排列，无需配置。建议图片底部为按钮预留空间。

## 六、商品价格、纯度和星级：原表 11、12

**入口：运营管理 → 商品管理 → 编辑商品。**

### 商品基础字段

| 配置字段 | 说明 |
| --- | --- |
| 产品名称（英文） | 商品卡片展示名称，也是联系 WhatsApp 时自动带入的商品名称 |
| 纯度标签（英文） | 例如 99% purity；可留空，留空不展示 |
| 推荐指数（星级） | 填整数 1—5；可留空，留空不展示星星 |
| 简介（英文，列表不展示） | 可继续维护，商品列表卡片不展示简介 |

推荐指数是后台设置的推荐程度，不是用户评价，不需要维护评价人数。

### 规格价格

在商品的 SKU（Stock Keeping Unit，商品规格单元）表格中，分别填写「原价」和「优惠价」，点击商品编辑区的「保存」。每种规格单独定价，不同规格可设置不同优惠。

已有商品还可在规格行点击「独立改价」，填写两种价格并点击「保存价格」。如果商品编辑页存在未保存内容，先保存商品，再独立改价。

| 规则或示例 | 官网效果 |
| --- | --- |
| 原价 100.00，优惠价 80.00 | 显示优惠价、划线原价及 20.00 的优惠金额，附对应币种 |
| 原价 100.00，优惠价 100.00 | 只显示当前价格，不显示优惠标签和划线原价 |
| 优惠价高于原价 | 不允许保存 |
| 小数位超过币种精度 | 不允许保存；例如 USD（美元）最多两位小数 |

价格必须非负。草稿规格可暂不定价，但原价与优惠价应同时填写或同时留空。已有价格在数据库升级时按原价等于现有售价处理，不自动生成优惠。

商品列表页和首页 Featured products. 使用相同卡片。多规格商品展示最低有效优惠价，对应原价和优惠金额均取同一个规格。

### 首页展示条件

在商品编辑页「首页展示」区域开启「首页推荐」，设置「首页排序」，并确认商品已上架且至少有一个启用、有效定价的规格。首页最多显示 6 个商品，排序较小优先。

「首页推荐」是是否进入首页的开关；「推荐指数（星级）」是卡片星级，两者用途不同。

两处商品卡片中的 Contact us 无需单独配置。点击后使用统一客服弹窗，在 Open WhatsApp 打开的聊天中预填商品名称，并保留客服问候语；不会自动发送消息。

## 七、两处品牌介绍：原表 13、20

### 轮播下方的品牌与指标区域：原表 20

**入口：系统配置 → 品牌与主题 → 首页品牌介绍与指标。**

| 配置字段 | 说明及示例 |
| --- | --- |
| 顶部标记 | 品牌上方的小标签，例如 Manufacturer Direct • Research Supply |
| 品牌第 N 段 | 将品牌拆为多个部分，每部分独立设置文字和颜色；例如 NOVA 蓝色、PEPT 黑色 |
| 介绍描述 | 品牌下方的独立介绍文字，可换行 |
| 指标 N 数据文本 | 例如 ≥99%、24h、150+、COA，可包含符号和英文，不限数字 |
| 指标描述 | 对应数据的解释，例如 Purity Guaranteed、Response Time |
| 上移／下移／删除 | 管理品牌分段或指标的顺序与内容 |

最多维护 10 个品牌分段、20 项指标。品牌分段按顺序直接拼接展示，需要间距时在文案中保留空格。填写后点击「保存品牌与主题」。

初始化提供 NOVA 与 PEPT 两段品牌和四项指标：≥99% / Purity Guaranteed、24h / Response Time、150+ / Countries Served、COA / Every Batch Verified。COA 指 Certificate of Analysis（分析证书）。示例内容须按实际情况核实。

该区域固定显示 Get Pricing on WhatsApp 和 View Products 两个按钮，无按钮配置项。区域没有独立总开关；如需隐藏，清空顶部标记与介绍描述，并删除全部品牌分段和指标，再保存。

### 首页原有介绍区域：原表 13

**入口：系统配置 → 品牌与主题 → Home 介绍标题、Home 介绍正文。**

这两个字段维护首页精选商品之后的介绍区域，与轮播下方的品牌指标区域独立。标题下方的 Contact us 由官网固定展示，复用统一客服流程。标题和正文均为空时，该区域隐藏。

## 八、统一 WhatsApp 联系配置

**入口：运营管理 → 客服配置。**

沿用现有国家／地区客服配置，维护「配置名称」「国家／地区」「配置启用」，以及账号的「客服名称」「国际号码（区号加号码，仅数字）」「问候语（选填）」「WhatsApp 账号二维码」「账号启用」。号码、二维码须为实际可用信息，并确保默认配置及可用账号正确。

各处联系按钮不分别填写号码。访客点击后先进入客服弹窗，再通过 Open WhatsApp 进入聊天。商品卡片的聊天预填文字会附加商品名称；二维码仍使用后台上传的账号二维码图片。

以下入口采用该流程：页眉 Contact us、轮播优惠联系按钮、各区域 Get Pricing on WhatsApp、商品卡片 Contact us、首页介绍 Contact us、联系区 WhatsApp — Direct Message，以及右下 WhatsApp 悬浮按钮。

以下操作有各自用途：Shop Now 打开关联商品；View Products 打开产品目录；左下 Special offer 打开优惠弹窗；优惠弹窗提交联系方式。

## 十、保存后检查

- 页眉颜色只影响页眉，宣传条颜色独立。
- 宣传条总开关与条目开关正确，顺序与速率符合预期。
- 有效关联商品的轮播显示 Shop Now，其他轮播仍有优惠联系按钮。
- 商品两种价格、优惠金额、纯度和星级在产品列表及首页一致。
- 商品联系按钮打开正确客服，聊天预填含商品名称。
- 两处品牌介绍修改的是各自对应字段。
- 背景图片可替换，清除并保存后恢复无图片外观。
- 优惠弹窗仍能提交联系方式，左下按钮仍能再次打开弹窗。
- 手机端文字清晰，按钮与轮播控件互不遮挡。

若保存提示配置已被修改，请记录尚未保存的内容，重新加载并核对后再保存。若按钮不可编辑，请管理员检查对应的配置修改、商品编辑或商品价格修改权限。
