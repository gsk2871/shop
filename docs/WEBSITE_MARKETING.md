## 配置与数据规则

新增站点配置存于现有 `site_config.payload`，沿用站点读取、更新权限、版本冲突检查及操作审计，不增加独立权限。

| 字段 | 规则 |
| --- | --- |
| `headerBackground` | 独立六位十六进制颜色，仅作用于页眉 |
| `backgroundMediaId` | 媒体库图片 ID；空字符串清除配置，`backgroundImage` 由后端解析，不能通过提交任意 URL 覆盖 |
| `announcement` | `enabled`、`background`、`textColor`、`speed`、`items`；速率为 slow／standard／fast，对应每秒约 30／50／80 像素 |
| `announcement.items` | 最多 30 条，每条 `text` 和 `enabled`，数组顺序为展示顺序；文字非空、最多 500 字节 |
| `brandIntro` | `tagline` 最多 200 字节，`description` 最多 2000 字节；纯文本展示 |
| `brandIntro.parts` | 最多 10 段，每段 `text` 非空、最多 100 字节，`color` 为六位十六进制颜色 |
| `brandIntro.metrics` | 最多 20 项，每项 `value` 非空、最多 100 字节，`description` 非空、最多 200 字节 |

颜色输入示例为 `#2563eb`。后台可调整品牌分段、指标及宣传条顺序。长度以服务端 UTF-8 字节限制为准。宣传条无启用内容时隐藏；内容不超出容器时静止；悬停或聚焦暂停；减少动态效果模式静态换行。清空的配置列表保持为空，重复执行种子不会补回已删除内容。

背景图片建立 `site_config / background` 媒体引用。被引用图片不能直接删除；清除配置后释放引用，保留媒体原始素材。前端使用整页覆盖背景，卡片、页眉和弹窗保留各自底色。

弹窗新增 `brandText`、`quoteLabel`、`quoteTitle`，沿用原配置接口和权限。新增种子分别为 NOVAPEPT、PRODUCT LIST & QUOTATIONS、Request a Quote.；新建配置主标题为 Want 10% off your first order?，提交文字为 Get your discount right now。已有配置仅补缺失字段，不覆盖运营已保存的主标题和提交文字，升级后可在后台调整。

商品 `purityLabel` 最多 100 字节；`recommendation` 可空，填写时必须为整数 1—5。未填写不显示标签或星星，简介只从卡片隐藏，详情及原始数据保留。

每个商品规格单独维护 `originalPrice` 和 `salePrice`，前后台都按币种小数位精确校验，优惠价不得超过原价。数据库使用整数最小货币单位，原价字段为 `product_sku_price.original_amount`。旧接口未传原价时按同次优惠价处理，避免产生虚构折扣。原价变更与优惠价变更都需要 `product.price.update` 权限。

公开价格增加 `originalPrice`、`displayOriginalPrice`、`discount`、`displayDiscount`。列表起价取最低优惠价的有效规格，原价和差额均取同一规格。两价相等时 `displayDiscount` 为空，不显示优惠标签和划线原价；存在优惠时差额由后端计算。

## 升级与种子

1. 备份数据库，准备后端、后台及官网构建产物。后台和官网的 `@shop/contracts` 为本地文件依赖，构建前须重新安装依赖以同步新增类型；不能直接使用旧的 node_modules 快照。迁移期间暂停旧服务写入商品价格，避免旧版本不写新列。
2. 使用既有部署入口执行后端 `-migrate`，应用 `000007_product_marketing.up.sql`：新增纯度、推荐指数和规格原价列，原价回填为现有售价，不自动产生折扣。
3. 执行后端 `-seed`。缺失的页眉背景初始化为浅蓝 `#eaf4fc`；宣传条提供六条示例、默认关闭、标准速率；品牌介绍提供 NOVA 蓝色与 PEPT 黑色分段，以及 ≥99%、24h、150+、COA 四项指标。种子只补缺失字段，重复运行不覆盖已保存配置，包括空列表。
4. 同步切换后端、后台及官网。确认 WhatsApp 原有账号有效，按实际业务核对示例文案与指标，开启宣传条、补录商品标签及推荐指数，按需配置背景图片。
5. 按需求清单逐项验收，包括桌面和手机、有效／失效关联商品、无折扣／有折扣、后台权限、配置清除和并发版本冲突。

迁移回滚会删除新增原价、纯度和推荐指数数据，保留当前优惠价；不是无损回滚。站点 JSON 配置保留在现有表中。需要回退时先保留数据库备份及新增字段数据，协调三端版本和服务停写窗口。

## 验证与安全检查

已进行源码复查及 Go 格式化，新增回归用例覆盖配置验证与空列表、种子幂等且不覆盖编辑、媒体引用建立和清除、价格权限、金额精度、折扣计算及推荐指数校验。数据库结构回滚测试已纳入第 7 个迁移。测试文件已编写，不代表执行通过。

安全源码检查覆盖本次改动及相关调用链：后台权限、价格更新权限、SQL 参数化、版本防覆盖、媒体引用保护与 URL 来源、纯文本及颜色渲染、WhatsApp 地址校验和商品名称编码。本次检查范围内未发现已证实安全问题。数据库并发行为、浏览器渲染与实际网络边界尚待运行验证。

当前本机没有可用容器运行时，macOS 隔离无法设置技能要求的内存硬限制，因此没有执行项目测试、构建或浏览器页面。需在有网络隔离、只读源码、临时可写目录、CPU／内存／进程／磁盘／时间限制的环境完成：

- 后端：`go test ./...`、`go vet ./...`、`go build ./cmd/server`；用临时 PostgreSQL 和 `TEST_DATABASE_DSN` 执行真实数据库测试，不能指向业务数据库。
- 后台：`pnpm run setup`、`pnpm run typecheck`、`pnpm run build`。
- 官网：`pnpm run typecheck`、`pnpm run build`、`node --experimental-strip-types --test tests/*.test.mjs`。
- 浏览器：按需求清单全部验收项检查，特别是滚动条减少动态效果、窄屏双按钮、商品聊天预填名称、背景清除恢复和优惠弹窗原流程。
