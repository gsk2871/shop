# 当前代码范围与需求映射

三个服务端或前端目录：单 Go 后端、React 管理后台、Next.js 英文官网。每个站独立配置和 PG 数据库。原始需求与回答文件均保留原样。

| 用户确认或本次要求 | 当前实现 |
|---|---|
| 后续网站独立域名、服务器 | 独立部署，无共享多租户 |
| 官网只需英文 | 英文官网，中文管理后台 |
| 一个管理员，不分权限 | 登录、退出、改密、操作日志；没有角色与权限分级 |
| 素材只上传、不转码 | 图片、PDF、MP4、WebM 本地上传、列表与引用，最大 20MB；无转码流程 |
| 文章无需审批、直接发布 | 草稿、发布、下线，官网只显示已发布内容 |
| 官网配置 | 品牌、Logo、主色、背景色、Banner、介绍、联系信息与科研声明 |
| Cookie 提示 | 本地偏好提示；没有启用分析脚本或 Consent Mode |
| 首次官网结构参考 Lazarus Labs | 大图首屏、文档介绍、研究文章、FAQ、联系入口；不复制原站品牌、产品或收费功能 |
| 国家 IP 对应 WhatsApp | 尚未实现；目前仅使用全局默认号码 |
| 商品管理与搜索 | 后台与 API 已实现 CRUD、搜索、多图及上下架；官网页面仍待接入 |
| 报告名与图片 | 尚未实现；页面保留空状态 |
| 表单字段另行提供、感谢页 | 尚未实现；联系页仅使用邮箱和 WhatsApp |
| 新线索无需通知销售 | 未引入通知服务 |

素材当前使用本地磁盘，OSS/COS/S3 适配仍待接入。文章编辑器当前为纯文本，原项目富文本与素材分类移动等能力未搬入。商品管理已实现；独立分类管理、检测报告与询盘仍未实现。

参考结构来源：[Lazarus Labs 首页](https://www.lazaruslabs.com.au/)，查看日期 2026-10-09。官网采用原创布局与文案，没有复制原站素材、真实产品数据或商标。

验证：Go 单测、静态检查及编译；后台类型检查及构建；官网类型检查、服务端渲染构建及首页浏览器预览。当前机器未运行 PostgreSQL，真实 PG 初始化及前后台内容联调尚未执行。
