# 实现范围与需求映射

后台固定中文，官网固定英文；独立站点采用单个 Go 服务、PostgreSQL、Cookie 会话及本地公开媒体。

| 需求 | 实现位置与行为 |
| --- | --- |
| 用户及权限 | admin_role/admin_user/admin_permission；43 节点树供菜单直接消费；三种默认角色；精确路由默认拒绝 |
| 安全登录 | 密码 → 一次性 TOTP 票据 → 完整 Cookie；首次改密和绑定；AES-GCM keyring；共享限流、防重放、再认证和恢复命令 |
| 管理操作 | 用户、角色授权及状态、日志、运行配置；并发保护最后有效超管 |
| 素材 | 流式上传图片／PDF／MP4／WebM；分页、搜索、类型筛选、预览、重命名、引用清单、删除保护及重试清理 |
| 产品 | 英文资料、自定义规格与 SKU、精确金额、独立价格及上架权限、富文本、版本控制、未保存预览 |
| 官网产品 | 已发布且有启用定价组合；搜索、分页、规格组合可用性、后端起价／选中价、详情 SEO、404 与服务故障区分 |
| 新闻 | 富文本和封面、置顶及顺序、首次发布时间、草稿／发布／下线、版本控制；官网分页及详情 |
| Banner | home_hero/products_header/research_header；任意条数、顺序、UTC 排期、图片与手机回退、CTA |
| 品牌主题 | Logo 引用、八种颜色变量、公司介绍、邮箱、默认 WhatsApp、科研声明、后台颜色预览及恢复默认 |
| 热加载 | 33 个 YAML 字段；独立资源候选、整版发布、失败保持旧版、在途租约、状态及来源 |
| 首次部署 | migrate → seed → run；必要系统种子幂等；配套数据库、媒体目录和密钥备份恢复 |

产品没有颜色维度、独立图库、库存、购物车、订单、支付或多币种换汇。首期只有 USD 种子；币种结构为扩展保留精度字典。视频只存原文件并支持 Range，不含转码或流媒体平台业务。检测报告业务、询盘收集与按国家号码分流不在本次范围，导航中的文档页提供询问入口。没有分析脚本，Cookie 提示用于保存偏好。

共享类型为 `@shop/contracts`，后台预览和官网详情由 `@shop/content` 渲染。三端一起切换新契约；不保留旧集合 PUT、单管理员认证、字符串正文或 Banner 数组兼容入口。
