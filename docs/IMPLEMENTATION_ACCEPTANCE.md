## 配套恢复演练

临时 PostgreSQL 17 使用独立端口 55432；从空库执行 migrate → seed → run。停写后将 shop_smoke 以 pg_dump 自定义格式备份，并归档媒体根目录和对应测试 keyring。创建 shop_restore、pg_restore，文件恢复到相同注册路径；保留 site_identity 和原加密密钥。

恢复后重复 seed，没有重置原账号密码或 MFA；启动历史密文检查成功。实际 HTTP 使用原凭据完成后续测试账号管理，浏览器会话、已发布产品和文章仍可读，视频可播放。恢复时核对：43 权限节点、38 权限、3 角色、USD、3 投放位、1 已发布产品、1 已发布文章、12 Banner、2 媒体、1 storage root 均完整。
